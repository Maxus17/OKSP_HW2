# Происхождение исходников ДЗ 2

Основной репозиторий: https://github.com/Maxus17/OKSP_HW2

Локальная версия подготовленного стенда: `ea2cb3fed7958791fb61fde4a934b7596f820419`.

Код приложения, SQL, зависимости, сценарии k6, сборщик ресурсов и профилировщик перенесены побайтово из этой версии. В публичном .env.example значения паролей очищены. README и инструкция обновлены для отдельного репозитория OKSP_HW2.

Публикация через API GitHub создаёт новый идентификатор коммита. Он не подменяет SHA, сохранённый в metadata.json ранее выполненных серий. Для новых измерений нужно использовать git rev-parse HEAD из клона OKSP_HW2; исходные SHA-256 файлов каждой серии фиксируются скриптом.

Результаты испытаний, .env и локальная история Git в репозиторий не включены. Полученные ранее измерения должны сохранять исходные метаданные версии и даты.
